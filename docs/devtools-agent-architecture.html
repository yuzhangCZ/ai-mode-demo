模块与执行上下文

  • • 7 模块：MAIN / RENDERER_PROJECT / 4×webview / UTILITY_BACKEND
  • • agentpage 内 4 子模块：调试 UI · AgentLoader · instanceframe · subcontext
  • • 5 个 JS 上下文互隔离；instanceframe 与逻辑层同构不同 wx 注入集
  • • MagicBrush 模拟 glass-easel 卡片渲染（工具内备用）

三条消息线

  • • ① 页面装配线：utility 进程本地 HTTP 吐 agentPage.html + __agentData（启动一次）
  • • ② Agent 专线：CMD 70-73 集散于 RENDERER_PROJECT，wx.* 借道后复用 appservice SDK
  • • ③ 接力线：openMiniProgram(handoff) → 场景值 1454 → OnAppRoute → wx.onAgentHandoff
  • • 各 webview 互不可见 JS 变量，跨层调用均经项目进程（wx API 本体）中转；storage 是唯一打通点

NDJSON 调试通道

  • • 一次性 POST 非流式；一次提问 = 多次 sendAgentChat 回传驱动推理
  • • skill_data（SKILL.md + mcp.json）每次全量上行，改完即生效无需发版
  • • 上下文 = 会话线(session_id) + 能力线(无状态) + 状态线(共享 storage)
  • • mcp.json 单 skill 限 24000 字符（CLI 路径校验）
