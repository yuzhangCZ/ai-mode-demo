一套协议 · 两个平面 · 三个域：客户端 ⇄ NDJSON 单端点 ⇄ 网关（接入协议面 + MCP 工具面）⇄ Agent（决策 · 会话 · 上下文）· 能力提供方经工具面挂接

总体架构 网关对接客户端与 Agent · 客户端仅对接一套协议（NDJSON 单端点 · 三类流复用）

三域职责

  • • 客户端：零决策执行宿主（A 链客户端运行时 ‖ B 链薄执行器 · 小程序运行时）
  • • 统一网关：接入协议面（协议转换·流式透传）+ 工具面（MCP 注册表·适配·归一）+ 能力提供方 · 无会话状态
  • • Agent：决策 + 会话与上下文 · 基础工具层与 _skills_index 常驻 · 外部能力经工具面

一套协议

  • • 客户端 ⇄ 网关：NDJSON 单端点，三类流复用（query/回复 · tools/call·result · 流式进度）
  • • 网关 ⇄ Agent 双通道：问答通道（对话 · 回复流）‖ 工具通道（工具注册 · tools/call ⇄ 结果）
  • • 端侧工具执行（tools/call）借道同一会话通道，无独立调用协议
  • • MCP 调用是后端内部事务，客户端无感知

能力接入（MCP）与边界

  • • 发现：_skills_index 常驻上下文 · 加载：read_skill 渐进披露
  • • 调用：胖技能派发子代理（云端脑）· 轻量工具 Agent 内置直连
  • • 业务数据 wx.request 直连（原子接口执行 ‖ 接力页闭环）· 不入网关（≤200KB 摘要）
