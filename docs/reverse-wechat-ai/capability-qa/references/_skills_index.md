## 加载某项能力 reference 的 `read_skill` 调用范式

需了解某能力详情时，用 `read_skill` 加载上表对应能力的 reference 文件后再作答（禁止凭印象）。

- 直接复制上表「填以下参数调用read_skill读取reference」列中该能力对应行的整段 JSON，作为 `read_skill` 的入参原样传入；**不要**自行拼接或改写 `file_path` / `skill_name`。

例：查"小工具"能力，照搬其所在行该列的 JSON 调用：

```json
{"file_path": "references/能力描述.md", "skill_name": "create_minitool"}
```

多项交叉需对每个相关 ref **各调用一次 `read_skill`**（一次只读一个文件），全部加载后再综合作答。如"你能处理图片吗"要分别照搬 3 行对应列的 JSON 调用：

```json
{"file_path": "references/能力描述.md", "skill_name": "multi-modal-understand"}
{"file_path": "references/能力描述.md", "skill_name": "finderaigc-manager"}
```
