# 小程序（mini-app）

> 分类：出行生活 | 召回关键词：小程序、打开小程序、查天气、点外卖、打车、查快递、买票、订酒店、点奶茶咖啡、充话费、扫码点餐、智能家电遥控
> 一句话：在微信里帮你**打开并真实操作微信小程序**，完成下单、查询、导航等实际任务。

## 是什么
微信小程序智能助手。把你的自然语言意图翻译成"打开哪个小程序 + 在里面做什么"，并通过自动化在小程序内真实完成下单 / 查询 / 操作。

## 能帮你做什么（支持范围 ✅）
- **本地生活下单**：点外卖、奶茶咖啡、扫码点餐、堂食排队、KTV、洗车、家政。
- **出行**：打车（滴滴等）、共享单车、查公交地铁、查驾车路线、查火车票 / 机票、订酒店。
- **票务**：电影票、演唱会票、景点 / 展览门票、博物馆预约。
- **查询**：天气查询、快递物流、订单状态、附近商家 / POI、营业时间。
- **充值缴费**：手机话费、加油卡、水电燃气、ETC。
- **智能家电**：空调 / 冰箱 / 洗衣机等的远程操控与状态查询。
- **模糊本地服务**："我想吃饭""附近有什么好玩的""帮我找个能 X 的小程序"。
- **基于上一次操作截图的追问微调**："换成大杯""看第二家""下一场"。

## 不支持 / 做不了（❌ 明确边界，避免误答）
- **航班订阅、关注、提醒通知类需求**，例如：航班订阅、关注航班、航班起飞了通知我 → 走任务中心，不走小程序。
- **纯知识 / 资讯问答**（"火锅热量多少""哪个航司服务最好"）→ 走通用问答，不操作小程序。
- **仅查询"哪个小程序能做某事"**而不需要实际操作时不触发——只有要"操作"小程序才走本能力。
- 明确要求用 **App / 网页 / 桌面客户端**（非小程序）完成的不走本能力。
- 调用**非微信生态平台**（如直接调淘宝/抖音内部）不属本能力。
- **批量点赞 / 批量评论 / 批量转发**不操作。
- **实际付款最后一步**需你在小程序内自行确认，不会自动点"立即支付"。

## 易混淆区分（避免张冠李戴）
- "查下我的航班起点起飞" → 小程序（实际操作）；"我的航班起飞前1h提醒我" → 走任务中心。
- "帮我点一杯喜茶 / 帮我打车回公司" → 小程序（实际操作）；"哪个小程序能点奶茶" → 不触发（只是查询）。
- "查快递到哪了" → 小程序；"导航去某地 / 国内景点在哪" → 走地图服务。
- "把这张图变成动漫风" → 走 AIGC 图像生成，不是小程序。
