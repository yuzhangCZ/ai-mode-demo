声明类

开发者上传 → 云端存储 → AI 会话启动时预载到 Agent ※
（预载时机为推测；"先于代码到位"由架构必要性推出）
  • app.json: agent.skills[] — SKILL 列表（≤30）
  • AGENTS.md — 全局提示词（≤10000B）
  • SKILL.md — 业务说明（≤16000B）
  • mcp.json — 工具清单（≤24000B，排除 outputSchema 与空白字符后计算）
    • apis[]: inputSchema / outputSchema + _meta.ui.componentPath
    • components[]: path / pagePath + 可选 realtime / expirable / expiredText
  • page-meta.json — 服务直达（≤8000B）
